## ১. একাদশ শ্রেণির (১ম বর্ষ) গোল্ডেন সূত্রসমূহ (এক নজরে)

### পদার্থবিজ্ঞান ১ম পত্র
- **ভেক্টর লব্ধি:** `R = √(P² + Q² + 2PQ cosα)` এবং `tanθ = (Q sinα) / (P + Q cosα)`
- **নদী পারাপার:** ন্যূনতম সময়ে পার হতে `α = 90°` (`t_min = d / v`); সোজাসুজি বা ন্যূনতম দূরত্বে পার হতে `cosα = -u / v`
- **প্রাসের গতি:** `H = (v₀² sin²θ) / 2g`, `R = (v₀² sin2θ) / g`, শর্টকাট: `tanθ = 4H / R`
- **রাস্তার ব্যাংকিং:** `tanθ = v² / (rg) = h / w`
- **মুক্তিবেগ:** `v_e = √(2gR) = √2 · v_o ≈ 11.2 km/s`

### রসায়ন ১ম পত্র
- **বোর বর্ণালি (রিডবার্গ সমীকরণ):** `1/λ = R_H (1/n₁² - 1/n₂²)` (`R_H = 109678 cm⁻¹`; দৃশ্যমান অঞ্চল = বামার সিরিজ `n₁ = 2`)
- **হেন্ডারসন-হ্যাসেলবালখ (অম্লীয় বাফার):** `pH = pKa + log₁₀([Salt] / [Acid])`
- **ক্যালকুলেটর ছাড়া pH শর্টকাট:** `[H⁺] = a × 10⁻ᵇ M` হলে `pH = b - log₁₀(a)` (`log 2 = 0.30, log 3 = 0.48, log 5 = 0.70`)
- **ব্যতিক্রমী ইলেকট্রন বিন্যাস:** `Cr(24) = [Ar] 3d⁵ 4s¹` এবং `Cu(29) = [Ar] 3d¹⁰ 4s¹`
- **ইলেকট্রন আসক্তির ক্রম:** `Cl > F > Br > I` (আয়নীকরণ শক্তি: `N > O` এবং `Be > B`)

### উচ্চতর গণিত ১ম পত্র
- **ম্যাট্রিক্স নির্ণায়ক:** `n × n` ক্রমের ম্যাট্রিক্সের জন্য `|kA| = kⁿ |A|`
- **লিমিট শর্টকাট:** `lim(x→0) (1 - cos ax) / x² = a² / 2` এবং `lim(x→0) (e^(ax) - e^(bx)) / sin(cx) = (a - b) / c`
- **নির্দিষ্ট যোগজীকরণ:** `∫₀^(π/2) sinⁿx / (sinⁿx + cosⁿx) dx = π / 4` এবং `∫ e^x [f(x) + f′(x)] dx = e^x f(x) + c`

### জীববিজ্ঞান ১ম ও ২য় পত্র
- **ক্রসিং ওভার:** মায়োসিস-১ প্রোফেজ-১ এর **প্যাকাইটিন (Pachytene)** উপ-পর্যায়ে ঘটে।
- **সালোকসংশ্লেষণ:** `C₃` চক্রের ১ম স্থায়ী যৌগ **3-PGA**; `C₄` (ভুট্টা, আখ) চক্রের ১ম স্থায়ী যৌগ **অক্সালো অ্যাসিটিক এসিড (OAA)**।
- **জিনতত্ত্ব অনুপাত:** অসম্পূর্ণ প্রকটতা `1:2:1`, মারণ জিন `2:1`, পরিপূরক জিন `9:7`, প্রকট এপিস্ট্যাসিস `13:3`।
