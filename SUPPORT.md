# Support

## Using Nokkhotro

For setup questions, ideas, and general help, use the [structured issue chooser](https://github.com/abn21noman-create/Website-for-education/issues/new/choose). Community members can help there, and answers remain searchable.

For a reproducible software bug, choose the bug report form. Search existing issues first.

The public production app is available at [nokkhotro-hsc-2028.vercel.app](https://nokkhotro-hsc-2028.vercel.app).

## Protect your privacy

Never post passwords, access tokens, private keys, full student records, or screenshots containing names, email addresses, or other personal information. Use made-up data when demonstrating a problem.

Security vulnerabilities must be reported privately according to the [Security Policy](SECURITY.md).
